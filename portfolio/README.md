# Nayan Shirodkar — Portfolio

One-page portfolio website. Static HTML/CSS, no build step.

- `index.html` — the whole site
- `assets/` — headshot, website screenshots, social creative, and compressed video ads (with poster frames)

To publish, upload the `portfolio/` folder contents (index.html + assets/) to any web host,
e.g. Hostinger File Manager → `public_html/`.
