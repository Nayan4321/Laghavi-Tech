SARALA USER ACCESS  (Shopify app)  -  SETUP GUIDE
=================================================

What the app does
-----------------
- Extra sign-up / profile fields (text, number, date, dropdown, radio, checkboxes, yes/no).
  Answers are saved on the customer in Shopify (customer metafields).
- Smart tags: tag customers by their answers (for example "Wholesale").
- Approve new accounts: new customers get tag "sarala-pending" until you approve them.
- Members only: lock the whole store, or chosen pages / collections / products.
  Only certain tags (e.g. VIP) can be allowed.
- Hide prices and add-to-cart from guests ("Sign in to see prices").
- Sign-in bar for guests, and "after sign in, go to page X" by tag.
- Messages on the customer's account page (waiting message, per-tag announcements).
- Fake sign-up check: throwaway emails, random addresses, links in names are tagged
  "sarala-suspicious" so you can review or delete them.
- One plan, 15-day free trial, Shopify billing. Everything included.

The app stores NO customer data on your server. All data stays in Shopify.
Your server only stores each store's Shopify access token (MySQL table "sarala_shops").


STEP 1 - Server  (DONE)
-----------------------
The app server is PHP and runs on your Hostinger Premium shared hosting:
  https://sarala.laghavi.site   (folder public_html/sarala)
  Database: u469315892_sarala (created; the password is already in the config file).
  Store logins are kept in the table "sarala_shops" (made automatically).


STEP 2 - Create the app in the Partner Dashboard
------------------------------------------------
1. partners.shopify.com (or dev.shopify.com) -> Apps -> Create app -> "Create app manually".
   Name: Sarala User Access
2. Copy the Client ID and the Client secret.
3. Open shopify.app.toml in this folder and put the Client ID in  client_id = "..."
4. App URL: https://sarala.laghavi.site  (shopify app deploy in step 5 sets this anyway.)


STEP 3 - Put the Client ID and secret on the server
---------------------------------------------------
hPanel -> Files -> File Manager -> domains/laghavi.site/public_html/sarala/private/config.php
-> Edit. Replace PASTE_CLIENT_ID_HERE and PASTE_CLIENT_SECRET_HERE, Save.
(Do not change the db lines.) Until this is done the app pages show "not set up yet".
Never send the secret in chat or email.


STEP 4 - Pricing (Shopify managed pricing)

Partner Dashboard -> your app -> Distribution -> Shopify App Store listing ->
Pricing -> "Managed pricing" -> Add plan:

UPDATING THE SERVER LATER
-------------------------
On your computer: npm install, npm run build (makes php/assets/app.js), then upload
the php/ folder contents to public_html/sarala (keep private/config.php on the server).


STEP 5 - Send the extensions to Shopify
---------------------------------------
On your computer (with Shopify CLI:  npm i -g @shopify/cli ):
   cd shopify-sarala
   npm install
   cd extensions/sarala-account && npm install && cd ../..
   shopify app deploy
This uploads the app settings, the theme embed "Sarala access" and the
customer account blocks "Sarala profile fields" / messages.


STEP 6 - Requests in the Partner Dashboard (needed before review)
-----------------------------------------------------------------
1. API access -> Protected customer data access -> Request access.
   Choose: Name, Email. Reasons: "Show customers to approve or review in the app,
   apply tags based on the customer's own answers." Fill the data protection form
   (data not stored on our servers, only processed through Shopify's API).
2. API access -> "Allow network access in customer account UI extensions" -> Request.
   Reason: "After a customer saves the profile form, the block calls our app
   (https://sarala.laghavi.site/api/account/saved) to add the smart tags."
3. Privacy policy URL:  https://laghavi.site/sarala-user-access-privacy/
   (create this page on your website; text below).


STEP 7 - Test in a development store
------------------------------------
Partner Dashboard -> Stores -> Add store -> Development store.
Install the app, then check:
  [ ] Install -> you are sent to the pricing page -> approve the test charge.
  [ ] Sign-up fields: add 2-3 fields with a smart tag, Save.
  [ ] Settings -> Checkout and accounts -> Customize customer accounts:
      add "Sarala profile fields" on Profile page, messages block on Orders page.
  [ ] As a customer: fill the fields, Save -> answers + tag appear on the customer in admin.
  [ ] Access: lock a page, hide prices -> open the store logged out and logged in.
  [ ] Turn on approval -> new customer gets "sarala-pending" -> Approve in "Customers to review".
  [ ] Sign up with test@mailinator.com -> appears under "Look fake".
  [ ] Uninstall + reinstall works.
If something does not work, send me the exact error text and a screenshot.

Sarala User Access - Privacy Policy

Sarala User Access ("the App") is made by Laghavi Tech. This policy explains which
information the App uses when a merchant installs it on a Shopify store.

What we access: when installed, the App can read and change customer records of the
store through Shopify's API: names, email addresses, tags and the answers customers
give in the App's profile fields. This is used only to show customers to the merchant
for approval or review, to add tags, and to show the right content on the storefront.

What we store: customer information and answers are stored in the merchant's Shopify
store, not on our servers. Our server stores only the technical login session that
Shopify gives the App (shop domain and access token).

Sharing: we do not sell or share any information with third parties.

Deleting data: when the App is uninstalled, its login session is deleted. Shopify's
privacy requests (customer data request, customer redact, shop redact) are handled
automatically; shop data is removed 48 hours after uninstall.
