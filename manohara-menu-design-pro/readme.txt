Pro add-on for Manohara Menu Design: mega menus built like pages, for any theme's menu, plus icons, badges, WooCommerce parts and header features.

== Description ==

Manohara Menu Design Pro needs the free Manohara Menu Design plugin. Enter your license key under Appearance › Manohara Pro license.

= Mega menus =

1. Appearance › Mega Menus › Add New Mega Menu: pick a starting design (or start blank, with the block editor or Elementor) and build the panel like a page. Publish it.
2. Appearance › Menus: open a top-level item and choose the mega menu under "Mega menu". Or click "Create new" there; the new mega menu is linked to the item automatically.
3. The mega menu opens under that item.

* Works with your theme's own menu (classic themes such as Astra, GeneratePress, OceanWP, Twenty Twenty-One, and page-builder headers whose menu is a WordPress menu), and with menus drawn by Manohara. Nothing in your header has to be replaced.
* 10 starting designs with live previews: classic columns, icon cards, intro and links, features and showcase, dark icon tiles, store columns and banner, side tabs, resources and highlight card, wide columns and footer row, and your menu as columns. Every part is normal blocks you can change.
* Use what you already have: any Elementor template or block editor synced pattern can be the mega menu of an item.
* "Tabs (mega menu)" style for the Group block: each inner group becomes a tab, its first heading the tab's name.
* "Menu links" block: shows a menu from Appearance › Menus as columns, cards or small headings, with Pro icons and descriptions; edit the links in the menu.
* WooCommerce blocks (products, categories) work inside mega menus too.
* Per mega menu: content width, full screen width or below its item; maximum width; shadow.
* The panel opens on hover, keyboard focus or tap, stays on the screen, works with sticky and transformed headers, and closes with Escape or a click elsewhere.
* Phones and tablets (below the tablet breakpoint in the free plugin's settings): the mega menu opens inside the menu, under its item, with an arrow button, and columns stack.
* Theme menu styles are undone inside the panel, so it looks as it does in the editor.

= Menu items =

* Icons: 57 built-in line icons, Dashicons, Font Awesome classes (when your theme or Elementor loads Font Awesome) or an image from the media library.
* An image for cards, carousels and product tiles.
* A badge (New, Popular, -20%) in any colour.
* The item's description under its label.
* Hide an item on desktop, tablet or mobile.

= Header and menu button (per device, on the design screen) =

* Sticky header: stays at the top, stays and gets smaller, or hides when scrolling down and comes back when scrolling up.
* Eight menu button styles with their own animations, and text next to the button.
* A different logo on this device (for example a small mobile logo).
* Side panel width.
* Swipe the panel to close it.
* Tap to open: on touch screens, the first tap on a parent item opens its submenu and the second follows the link.
* Hide page elements on a device (CSS selectors), for example a second theme menu or a desktop-only bar.
* The breakpoints for desktop, tablet and mobile are set in the free plugin's settings and are used by all Pro features.

= WooCommerce =

* Cart button with the number of items, updated when a product is added, and a My account button.
* The count on menu items that link to the cart page.
* WooCommerce's own product and category blocks can be used in mega menus.

= Multilingual sites =

Works with Vacanam Language Switcher, Polylang, WPML and TranslatePress, and with right-to-left languages.

* Each language's menu keeps its own icons, badges and mega menus. When Vacanam copies a menu for a new language, the item settings are copied too, so you only translate the texts.
* With WPML, translated items without settings of their own use the original item's settings.
* Mega menus, synced patterns and Elementor templates are shown in the visitor's language when they are translated.
* The text next to the menu button and the device logo are registered for string translation.
