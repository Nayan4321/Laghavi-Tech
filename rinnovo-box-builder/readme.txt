The flexible box builder shared by every Rinnovo Pro plugin. Comes in the download package of each Rinnovo Pro.

== Description ==

Rinnovo Box Builder lets customers build a box from your WooCommerce products: fixed boxes, pick-your-items boxes with minimum and maximum items, box sizes, scheduled boxes (day-wise and rotating menus with selection deadlines), preference-based and hybrid boxes. It shows a step-by-step builder with a live total, checks stock and rules, and saves a snapshot of every box (items, variations, quantities, prices) on the subscription and the order.

It only builds and validates the box. Billing, stock, shipping and renewals stay in the Rinnovo Pro plugin that uses it (for example Physical Subscription Boxes Pro or Bundles & Variable Subscriptions Pro).

* Needs the free Rinnovo Subscriptions & Licenses plugin and at least one active Rinnovo Pro plugin.
* No license of its own: it keeps working when a Pro license expires. All main settings are in the Pro plugin.
* Elementor widget, block and the [rinnovo_box_builder] shortcode.

== Installation ==

1. Unzip the Rinnovo Pro download package: it holds the Pro plugin zip and rinnovo-box-builder.zip.
2. Upload and activate both in Plugins › Add New › Upload.
